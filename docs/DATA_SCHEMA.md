# Data Schema — Adaptive Cloud Security System
> Canonical reference for all data structures exchanged between components.
> All timestamps: **UTC ISO-8601**. All IDs: **UUID v4**.

---

## MetricPayload
Sent by the Windows agent to `POST /api/v1/ingest`.

```
Field                   Type            Required  Notes
─────────────────────────────────────────────────────────────────────────────
agent_id                UUID            ✅        Registered agent UUID
collected_at            datetime (UTC)  ✅        When snapshot was taken on agent
cpu_percent             float [0,100]   ✅        Overall CPU usage %
memory_percent          float [0,100]   ✅        RAM usage %
memory_used_mb          float ≥ 0       ✅        RAM used in MiB
disk_read_bytes_sec     float ≥ 0       ✅        Disk read throughput bytes/sec
disk_write_bytes_sec    float ≥ 0       ✅        Disk write throughput bytes/sec
net_bytes_sent_sec      float ≥ 0       ✅        Network TX bytes/sec
net_bytes_recv_sec      float ≥ 0       ✅        Network RX bytes/sec
active_connections      int ≥ 0         ✅        TCP connections in ESTABLISHED state
process_count           int ≥ 0         ✅        Total processes running
top_processes           [ProcessInfo]   ✅        Top 10 by CPU (can be empty list)
event_log_errors_1m     int ≥ 0         ✅        Windows Event Log ERRORS in last 60s
event_log_warnings_1m   int ≥ 0         ✅        Windows Event Log WARNINGS in last 60s
```

### ProcessInfo (nested in top_processes)
```
Field         Type        Required  Notes
───────────────────────────────────────────
pid           int         ✅        Process ID
name          string      ✅        Process name (e.g. "svchost.exe")
cpu_percent   float ≥ 0  ✅        CPU % for this process
memory_mb     float ≥ 0  ✅        RAM used by process in MiB
```

## MetricRecord (DB row — extends MetricPayload)
Stored in `metrics` table after ingestion.

```
Field          Type            Notes
────────────────────────────────────────────────────────
id             UUID (PK)       Generated server-side
agent_id       UUID (FK)       → agents.id
collected_at   datetime (UTC)  Partition key (monthly)
ingested_at    datetime (UTC)  Server ingestion time
<all MetricPayload fields>
top_processes  JSONB           Serialised array
```

---

## PredictionRecord
Generated by ML inference service after each metric ingestion.

```
Field           Type            Required  Notes
────────────────────────────────────────────────────────────────────────
id              UUID (PK)       server    Generated server-side
agent_id        UUID (FK)       server    → agents.id
metric_id       UUID (FK)       server    → metrics.id
predicted_at    datetime (UTC)  server    Inference timestamp
label           enum            server    See Attack Labels below
confidence      float [0,1]     server    Model probability score
model_version   string          server    e.g. "v1.0.0"
features_used   [string]        server    Feature names used for prediction
```

### Attack Labels (enum)
| Label | Description |
|-------|-------------|
| `benign` | Normal system activity |
| `brute_force` | Repeated failed auth attempts |
| `ddos` | Distributed denial-of-service traffic |
| `port_scan` | Systematic port probing |
| `unauthorized_access` | Unexpected privileged access |
| `suspicious_process` | Anomalous process behaviour |

---

## AlertRecord
Generated when `label != "benign"` AND `confidence >= alert_threshold` (default: 0.80).

```
Field           Type            Notes
──────────────────────────────────────────────────────
id              UUID (PK)
agent_id        UUID (FK)       → agents.id
prediction_id   UUID (FK)       → predictions.id
alert_type      string          Mirrors label value
severity        enum            low | medium | high | critical
message         string          Human-readable description
acknowledged    bool            Default: false
acknowledged_by UUID (FK, null) → users.id
acknowledged_at datetime (null)
created_at      datetime (UTC)
```

### Severity Mapping
| Confidence | Label | Severity |
|------------|-------|----------|
| ≥ 0.95 | any threat | critical |
| 0.85–0.94 | any threat | high |
| 0.80–0.84 | any threat | medium |
| < 0.80 | — | (no alert) |
| any | ddos / brute_force | +1 severity level |

## AgentRecord (DB)
```
Field        Type            Notes
────────────────────────────────────────────
id           UUID (PK)
hostname     string          e.g. "WIN-SRV-01"
os_version   string          e.g. "Windows Server 2022"
ip_address   inet            Tailscale IP preferred
api_key_hash string          bcrypt hash — never stored plain
status       enum            online | offline
last_seen    datetime (UTC)
created_at   datetime (UTC)
revoked      bool            Default: false
```

## UserRecord (DB)
```
Field           Type            Notes
────────────────────────────────────────────
id              UUID (PK)
username        string (unique)
email           string (unique)
password_hash   string          bcrypt
role            enum            admin | analyst | viewer
is_active       bool
created_at      datetime (UTC)
last_login      datetime (null)
```

## MLModelRecord (DB)
Tracks training runs.

```
Field             Type            Notes
────────────────────────────────────────────────────────
id                UUID (PK)
version           string          e.g. "v1.0.0"
algorithm         string          e.g. "XGBoostClassifier"
trained_at        datetime (UTC)
training_samples  int
feature_names     [string]        JSONB array
label_classes     [string]        JSONB array
artifact_path     string          Path inside ml/models/
is_active         bool            Only 1 row active at a time
job_id            UUID            Training job reference
status            enum            queued | training | ready | failed
```

## PostgreSQL Table Summary

| Table | Partitioned | Indexes |
|-------|-------------|---------|
| `users` | No | username, email |
| `agents` | No | hostname, status |
| `metrics` | Yes (RANGE on collected_at monthly) | agent_id + collected_at |
| `predictions` | No | agent_id, metric_id, label |
| `alerts` | No | agent_id, acknowledged, created_at |
| `ml_models` | No | is_active, trained_at |
